# Database parity matrix

Fresh audit: 2026-09-06. The reference has 34 persistent entity structs; row 35 audits its migration strategy. TokenRouter additionally migrates five target-only durability tables (`audit_log_outboxes`, `jimeng_task_operations`, `task_operations`, `relay_quota_reservations`, and `relay_quota_reservation_review_events`), so its aggregate migration currently creates 39 primary-database tables.

Status totals: **26 PASS / 0 IN_PROGRESS / 0 NOT_STARTED / 0 BLOCKED_EXTERNAL / 9 INTENTIONAL_DEVIATION / 0 REFERENCE_PLACEHOLDER**.

`TestDatabaseMatrixSQLiteMigration` is the executable entity manifest: it runs the real startup migration twice, checks all 34 reference tables plus the five target-only durability tables, and checks critical routing, identity, accounting, recovery, audit, and idempotency indexes. A row is not marked PASS merely because that manifest creates its table.

The frozen 2026-09-06 external database gate used a newly initialized loopback-only Homebrew MySQL 9.5 server, a disposable PostgreSQL 17 container, and a disposable ClickHouse 24.8 container. The exact nine-test manifest passed independently on both relational engines: `TestDatabaseMatrixExternalMigration` verifies every `AllModels` table, critical indexes, exact Token/Ability/Redemption/QuotaData metadata, legacy-row-preserving upgrades (including `tokens.model_limits` from `varchar(1024)` to native text), fail-closed unsafe narrowing, a second startup migration, and post-restart connectivity; the remaining tests cover relational log retention, relay accounting and channel-key concurrency, system-task lease/cadence, audit-outbox leasing/delivery, subscription usage epochs, provider-neutral TaskOperation accounting, and Jimeng atomic lifecycle. The two ClickHouse tests passed configurable TTL addition/removal, DDL migration, raw insertion, stable audit-event retry deduplication, content readback, and retention lifecycle. The Redis selector and wiring are compile/static-verified, but no server binary, service, or cached image was locally available. `INTENTIONAL_DEVIATION` is used only where the compatible reference schema and observable behavior are tested but TokenRouter consciously retains a non-destructive compatibility, security, or durability difference whose removal would weaken an established production invariant.
